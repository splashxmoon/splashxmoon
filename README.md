### hey, i'm arun 👋

i build **[Friday](https://github.com/splashxmoon/friday)**, a free, open-source desktop app where Claude Code, Codex, Cursor and other coding agents work as one team.

i started it because i kept hitting my claude limit halfway through tasks. now when one agent runs out, another picks the task up with a record of what the first did and changed.

<a href="https://github.com/splashxmoon/friday"><img src="https://raw.githubusercontent.com/splashxmoon/friday/main/docs/assets/agents-in-session.png" alt="Friday: several coding agents working in one session" width="720"></a>

- **[splashxmoon/friday](https://github.com/splashxmoon/friday)**: agents split the work on one board, message each other, and hand off at usage limits. MIT, macOS / Windows / Linux, no account.
- **[friday-claude-plugin](https://github.com/splashxmoon/friday-claude-plugin)**: use Friday from inside Claude Code.
- **[clipmimic](https://github.com/splashxmoon/clipmimic)**: a Claude Code skill that studies a short video and writes a brief to make your own.
